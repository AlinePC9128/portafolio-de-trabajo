# Marketing Growth Lab

Dashboard demostrativo para explicar una estrategia de marketing digital desde la campaña hasta la oportunidad comercial.

## Qué demuestra

- Planeación multicanal.
- Funnel: awareness → consideration → conversion → retention.
- Métricas de Meta Ads, Google Ads, SEO y email.
- Lectura de GA4, Tag Manager y Search Console.
- Recomendaciones accionables basadas en datos.
- Traducción de resultados técnicos a lenguaje de negocio.

## Stack

HTML, CSS, JavaScript, JSON, visualización con barras CSS y estructura lista para conectar GA4, Power BI o una API de campañas.
